Overview

// what it is

README.md

Production-grade distributed vault system for cryptocurrency hot-wallet custody. It implements the uDDS (Universal Distributed Data Sealing) framework — zero-knowledge blind RSA decryption inside Trusted Execution Environments, so the server performs cryptographic operations on blinded ciphertext without ever accessing plaintext.

The result: even the operator of the sealing service cannot read what it unseals — confidentiality is rooted in hardware, not in policy.

Peer-Reviewed Research

// the paper behind the system

udds-ieee-csp-2026.bib

uDDS: Universal Distributed Data Sealing for TEE

Ivan Tsz Fung Wong, Sam Ng, Jason Lau

2026 10th International Conference on Cryptography, Security and Privacy (CSP 2026) · IEEE · Accepted

Trusted Execution Environments provide hardware-rooted confidentiality, yet their native sealing mechanisms remain platform-specific. uDDS is a universal distributed data sealing framework that provides a single, unified sealing interface across heterogeneous TEEs while preserving data confidentiality even from the sealing service operator.

Blind Decryption

Operator-oblivious unsealing — clients blind their ciphertext so uDDS decrypts without ever learning the plaintext.

Raft Consensus

Volatile-only secret replication across TEE memory via Raft — crash fault tolerance and rollback resistance without persistent storage.

Universal TEE Interface

A single sealing API across SGX, TrustZone, and Nitro Enclaves — write once, deploy to any platform without modification.

Production Validated

9-node AWS Nitro deployment across 5 regions — 315ms unsealing latency with full attestation and geographic fault tolerance.
